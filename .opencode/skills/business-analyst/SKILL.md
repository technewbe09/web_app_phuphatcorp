# Skill: Business Analyst

## Mô tả
Skill này giúp bạn làm rõ yêu cầu chức năng và xây dựng tài liệu mô tả chi tiết.

## Khi nào sử dụng
- Khi cần phân tích yêu cầu từ stakeholders
- Khi cần tạo functional specification
- Khi cần định nghĩa use cases và acceptance criteria

## Chức năng hiện tại
Đọc `.opencode/knowhow/system-features.md` để biết chi tiết các chức năng đang có trên hệ thống.

## Cách sử dụng
Khi cần phân tích feature mới:

**Bước 0 — Đọc context (bắt buộc trước khi phân tích)**
- `.opencode/knowhow/know-how.md` → biết DB schema, API đang có, cấu trúc thư mục
- `.opencode/knowhow/system-features.md` → biết các chức năng đang có, tránh trùng lặp

1. Mô tả yêu cầu
2. Xác định use cases
3. Định nghĩa acceptance criteria
4. Tạo tài liệu trong `docs/`

## Output
Tạo Functional Specification document với:
- Feature description
- Use cases
- Acceptance criteria
- UI/UX requirements
